# Playbook: brownfield-delta

1. Name the existing system / repo / process in one line.
2. Restate the desired delta (before → after) in two sentences.
3. Name the requester. Flag if missing.
4. In scope = only the delta. Out of scope = unrelated cleanup and rewrites.
5. Raw requirements list from the ask + any linked tickets (quote, do not polish).
6. Unknowns: what about current production we do not know yet.
7. Write `SCOPED-BRIEF.md`. Stop. Do not read the whole codebase yet (W verify comes later).
