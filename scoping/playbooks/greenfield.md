# Playbook: greenfield

1. Restate the ask in one sentence. Confirm with the user if ambiguous.
2. Name the requester (human). If unknown, write `requester: unknown` and add to Unknowns.
3. Write Intent (I): what success looks like for that human, not for the codebase.
4. List In scope (max 7 bullets). Push speculative features to Out of scope.
5. List Out of scope (at least 3 bullets — force exclusions).
6. Dump raw requirements / wishes as an unordered list (keep original wording).
7. Surface Unknowns (open questions). Do not invent answers.
8. Write `SCOPED-BRIEF.md`. Stop.
