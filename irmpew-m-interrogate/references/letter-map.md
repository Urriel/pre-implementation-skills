# Letter map (Edko / paper)

| Letter | Meaning |
|---|---|
| I | Intent |
| R | Requirements (checkable) |
| M | Model of the world while building |
| E | Evaluator — how we know R holds under M |
| P | Program / implementation |
| W | World / production / reality |

Inner loop: change P under fixed R/M/E, run E.
Outer loop: when W ≠ M or E fails, revise R/M/E — not only P.
